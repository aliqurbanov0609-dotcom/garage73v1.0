# GARAGE 73 — Pub & Kitchen

Мобильное меню гастропаба в ретро-неоновом стиле. Проект включает выбор AZ / EN / RU, загрузку, хаб кухни и бара, девять категорий кухни с деталями блюд, десять категорий бара и списки напитков. На широких экранах композиция адаптируется под десктоп.

## Технологии

TanStack Start, React 19, TypeScript, Vite, CSS-анимации, Lucide и Netlify Image CDN. Авторские изображения кухни и бара находятся в `public/img`. Каталог и словари находятся в `src/data/menu.ts` и содержат демонстрационные данные.

## Локальный запуск

Установите зависимости командой `pnpm install`. Запустите `netlify dev --port 8889`, затем откройте `http://localhost:8889`. Node.js 22.13+ или 24. Сборку и проверку развертывания выполняет Netlify.

## Навигация

Приложение открывается на выборе языка AZ / EN / RU; выбор языка запускает загрузку на 1,8 секунды и открывает хаб. BACK снимает один экран из стека; HOME очищает стек и открывает выбор языка. Escape повторяет BACK. Блюда и категории — настоящие кнопки всей площадью, карточки финальных списков напитков — обычные информационные блоки. Удержание категории бара запускает декоративную CSS-анимацию, короткое нажатие открывает список.
